## 3. 页面级改动与设计理由

### 3.1 今日（`features/today/pages/today_page.dart` 重写）

信息顺序按"我现在什么状态 → 今天还能吃多少 → 吃了什么 → 要记什么"排：

1. **渐变头**：日期 + 星期 + 问候（随时段变），右边一个圆形日历按钮直达日历。
   阶段胶囊 + 一句大字结论（经期第 N 天 / 距下次 N 天 / 开始记录你的周期）+ 一行依据（预测日期 · 置信度 · 基于几个周期）。
2. **热量环**：中心只留"剩余/已超"一个大数字；标题旁补"预算 1781"，否则用户没法自己核对。
   环的底轨从灰改成**品牌色淡影**（0 摄入时不再像"没数据"）。
3. **今日明细**：预算 − 摄入 + 运动 = 余额（公式仍只来自 `DailyEnergySummary.remainKcal`）。
4. **今天吃什么**（新增 `meal_slots_card.dart`）：四餐各一行，显示"1 条 · 174 kcal"或"还没记"；点任一行直接进选食物，**并把该餐次预选好**（`showFoodPicker(initialMealType:)`）。
5. **快捷入口**：记体重（弹层）/ 记运动 / 记饮食 / 来经期（经期中自动变"结束经期"）。
6. **洞察条**（新增 `insight_bar.dart`）：经期 → 补铁建议；排卵 → 体温说明；易孕 → 食欲说明；有预算 → 剩余可吃多少；都没有 → 提示先记一笔。**不编造健康结论**。
7. **经量 chips**：未记录时**不预选任何一档**（原来会默认选中"无"，等于替用户记了"没有经量"）。

页面测试：`test/today/today_page_test.dart`（5 条：空档案结构、点"来经期"落库并变头部、未记录不预选、有历史时显示预测、仓库层闭环）。

### 3.2 我的（`features/me/pages/me_page.dart` 重写）

- 渐变头展示"月记 + 档案摘要"，右上角铅笔直达档案页；
- 三组卡片：**记录**（身体档案 / 体重趋势 / 饮食记录 / 运动记录 / 7 天餐单）、**周期**（经期历史 / 每日提醒）、**数据与关于**（数据管理 / 外观 / 关于）；
- 每条 = 圆角色块图标 + 标题 + **状态副标题**（"今天已摄入 174 kcal" / "最新 54.5 kg"），不点进去也能读；
- 底部一行"月记 · 数据只存在这台手机里"，呼应隐私承诺。

### 3.3 日历（`calendar_page.dart` + `month_grid.dart`）

- 月份切换：两个圆形按钮 + 居中标题 + "今天"胶囊；
- 月历进卡：今天 = 品牌色实心圆白字（最强锚点），经期/排卵/易孕 = 淡色圆，普通日只留数字，周末略淡；
- 图例并进卡内并用细分隔线分开；
- 「最近周期」改成卡片列表，进行中的那段带"进行中"胶囊。

### 3.4 趋势（`trends_page.dart`）

三个图共用一张卡 + `AnimatedSize`：切换时只有内容变，卡框不动，不会"跳一下"。
分段控件由主题统一（选中 = 品牌色实心胶囊）。

### 3.5 饮食记录（`food_log_page.dart`）

- 顶部"今日已摄入 180 / kcal · 1 笔"改成大数字 + 单位小字；
- 四个餐次各一张卡（原来是没有边界的四段文字），空餐次写"没有记录"。

### 3.6 弹层（`food_picker.dart`）

- **键盘适配**：原来固定 82% 屏高，数字键盘弹起后"完成"按钮被压住 → 改成"可用高度（屏高 − 键盘）× 0.82"；

### 6.3 竖屏锁 → 横屏自适应（2026-11-22 再改）

**第一版**：MuMu 默认 1920×1080 横屏，App 首次装上去渲染成横幅（卡片被拉宽、首屏变形），
于是用 `SystemChrome.setPreferredOrientations` 锁竖屏 —— 结果触发异步窗口尺寸变化，
出现**画面缩放 + 底部黑边 + 点击坐标错位**。

**第二版**：改成 `AndroidManifest` 的 `android:screenOrientation="portrait"`，问题消失。
但这只是"回避"：系统会把竖屏画面居中放进横屏显示器，**左右留下黑边**——
黑边不是 Flutter 画的，是系统给竖屏窗口的留白（MuMu 默认窗口、平板分屏、折叠屏都会遇到）。

**第三版（当前）**：允许横屏 + 给内容加宽度上限。
- 清单移除 `screenOrientation`，改为 `android:resizeableActivity="true"`；
- `lib/app/app.dart` 的 `MaterialApp.builder`：横屏时把内容包进
  `Center + ConstrainedBox(maxWidth: 720)`，并用 `MediaQuery.copyWith(size:)` 让页面感知"窄屏"；
- 结果：背景铺满、卡片不再被拉成横幅、黑边消失（见 `docs/screenshots/22-landscape-centered.png`）。

取舍：横屏时左右会有 pageBg 色的留白（内容列居中），这是平板常见做法；
如果以后要真正利用宽屏，应做双栏（如左侧日历 + 右侧记录），而不是放开无限宽度。

### 6.4 MuMu 模拟器接入（测试环境）

- 连接：`adb connect 127.0.0.1:16416`（端口在 `vms/MuMuPlayer-12.0-1/configs/vm_config.json` 的 `nat.port_forward.adb.host_port`）；
- 实例索引是 **1**，`MuMuManager.exe info -v 0` 会报 `player index not found`，要用 `info --vmindex all`；
- 实测：Android 12 / 1080×1920 / 320dpi / release 冷启动 **1.17 s** / PSS **158 MB**；
- MuMu 是「硬件键盘」模式，`adb shell input text` 不弹软键盘，键盘遮挡类问题仍需 AVD 或真机验证。

### 6.5 日历左右滑动切月（2026-11 新增）

- 手势包在**日历卡外层**（不是整页）：纵向滚动列表、点日期、点图例都不受影响；
- 方向与主流日历一致：**手指往左划 = 往后翻**（下个月 / 下一年）；
- 用 `primaryVelocity` 判断方向并要求 |v| ≥ 120，慢慢拖一点点就抬手不会翻页（误触保护）；
- 进场动画用 `AnimatedSwitcher` + 小幅 `SlideTransition`（偏移 8%），配合 `_swipeDir` 让"往哪边翻"看起来是对的；
- **年视图下同一手势切年**（不是切月），行为与左右箭头一致；
- 测试：`calendar_swipe_test.dart` 4 条（左滑下月 / 右滑上月 / 年视图切年 / 轻拖不翻页 + 滑动后仍可点日期开弹层）；
- 真机（AVD）实测：11 月左滑 → 12 月，右滑回 11 月；年视图左滑 2026 → 2027。
