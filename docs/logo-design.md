## 附录 A · 原图标提取（最终采用）

### A.1 来源

旧包 `com.example.cycle_note` 1.0.0 解包后的资源目录：

```
<旧版 APK 解包目录>\res\mipmap-{m,h,xh,xxh,xxxh}dpi\ic_launcher.png
```

| density | 尺寸 | 大小 |
|---|---|---|
| mdpi | 48×48 | 3,439 B |
| hdpi | 72×72 | 6,645 B |
| xhdpi | 96×96 | 10,593 B |
| xxhdpi | 144×144 | 20,432 B |
| xxxhdpi | 192×192 | 33,163 B |

**旧包没有自适应图标**（没有 `mipmap-anydpi-v26/`），只有传统 PNG。
原图：浅粉蓝渐变方底 + 圆形柔光 + 粉紫女性侧脸 + 双弧线 + 右下月牙。

### A.2 接回工程的做法（`_tools/extract_icon.ps1` → `_tools/enhance_icon.ps1`）

**第一步 · 提取（原样）**：5 个 PNG 复制到 `res/mipmap-*/ic_launcher.png`，与旧包逐字节一致。

**第二步 · 优化（`enhance_icon.ps1`，只做还原度优先的处理：不重绘、不改配色）**：

| 处理 | 参数 | 为什么 |
|---|---|---|
| Lanczos3 放大 4× 成 768 母版 | 预乘 alpha，避免边缘发黑 | 源图只有 192，后面要出 432/1024；GDI+ 双三次会糊 |
| 轻量 unsharp mask | amount 0.45 / radius 1 | 找回放大后被抹平的边缘（侧脸轮廓、双弧线） |
| 传统图标重采样 | 768 → 48/72/96/144/192，**逐级减半**再 Lanczos | 一步 16× 缩小会欠采样，双弧线会断成虚线（实测） |
| 48/72 小尺寸 | 放大 4% + 饱和 ×1.06 / 对比 ×1.02 | 小图标上主体更满、线条更清楚 |
| 传统图标圆角 | 22% 半径、**真透明**四角 | 原图四角是不透明白粉色，桌面上会显示成方块 |
| 自适应前景 | 母版**满幅铺满**（1.03 过扫裁边），不裁圆、不加蒙版 | 之前"缩到 78% + 羽化"会在圆形裁切里露出一圈浅色方片；满幅交给系统裁切最干净 |
| 自适应背景 | 原图四角平均色 `#E1DDEE` | 仅作兜底（满幅前景基本看不见它） |
| 1024 商店图 | 母版 Lanczos 到 1024 + 轻锐化 0.25 | 比原版直接放大清楚一档（源图仅 192 的硬限制仍在） |

## 0. 先明确约束（决定了画法）

| 场景 | 规格 | 设计含义 |
|---|---|---|
| Android 自适应图标 | 108dp 画布 / 72dp 安全圆 / 内容缩到 66% | **前景不放文字、不放细线**；自带圆角底会被系统二次裁切，所以前景层必须无底 |
| 传统 mipmap | 48 / 72 / 96 / 144 / 192 | 需要自带 22% 圆角；48dp 下细节全部丢失，只能留"一个大形状 + 一个点" |
| 通知栏小图标 | 24dp 纯白剪影 | 必须有一个"单色也认得出"的形态 |
| 商店 / 分享图 | 512 / 1024 | 可以带字标与光斑 |
| 深色桌面 | 深底版本 | 现有启动页夜景用 `#7A2E38`，图标深色版沿用它 |

**结论**：图标主体只能是「一个大形状 + 至多一个强调点」；「月记」二字**不进应用图标**，只做字标（启动页 / 关于页 / 商店图）。

## 2. 五稿

### 稿 A｜月牙 + 周期点（现有图标的精细化）

```
   ┌─────────────┐
   │   ◗        · │   ◗ = 白色月牙（缺口朝右上 45°）
   │             │   · = 6% 直径小点，落在缺口延长线上
   └─────────────┘
```

- **几何**：底 = 全幅玫瑰渐变（`#F98A9B → #E4586F`，135°）；月牙 = 大圆(r=0.30W) 减 偏移小圆(r=0.28W, 偏移 +0.52r/−0.30r)；点 = 0.072W，位于月牙外 0.74W/0.30W 处（现参数）。
- **改动**：月牙再瘦 8%，点缩小到 0.06W 并移到缺口中心线上，让"月 + 点"读作**月相/周期节点**而不是"月亮旁边有颗星星"。
- **优点**：与现有图标连续，改造成本最低；小尺寸清楚。
- **缺点**：只有经期语义，减脂完全不体现。

### 稿 B｜环 + 点（热量环 × 月牙，双语义）

```
   ┌─────────────┐
   │    ╭───╮    │   缺口朝右上 45°、270° 粗弧
   │   │     │   │   弧 = 热量环 = 月牙轮廓
   │    ╰───╯ ·  │   · = 缺口中心的小圆点（今天/已记录）
   └─────────────┘
```

- **几何**：弧宽 0.16W、半径 0.30W、起止 −45°→225°（留 90° 缺口）；弧两端**圆头**（`stroke-linecap: round`）；点在缺口中心，直径 0.10W，纯白。
- **配色**：底 `#FDE7EC`（浅粉，不是满色）；弧 `#F98A9B → #E4586F`（沿弧的线渐变）；点 `#E4586F`。
- **为什么好**：**一个 C 形同时是"热量环"和"月牙"**，一眼双关；48dp 下仍然是一个 C + 一个点，不会糊。
- **缺点**：与"月"字的联想弱于稿 C。

### 稿 C｜「月」字负空间（汉字型，品牌名直读）

```
   ┌─────────────┐
   │  ┌──┐       │   外框 = 记录页/日历
   │  │──│       │   两横 = 记录线
   │  │  │       │   左撇 = 月牙弧（外扩）
   │  └──┘       │
   └─────────────┘
```

- **几何**：外框是 0.62W 的圆角矩形（r=0.10W），描边 0.11W；两条横线是 0.11W 的实心条；左侧竖撇由一段 90° 弧构成（半径 0.31W），弧的外缘超出外框 0.04W——**这一处外扩就是月牙的暗示**。
- **配色**：底满幅玫瑰渐变；图形纯白。**单色版**（通知栏/主题图标）直接去掉底色，只留白色笔画。
- **优点**：把品牌名可视化，"月" = 月/经期，"记" = 记录页；单色辨识度最高。
- **缺点**：48dp 下两条横线会粘连，必须做**两档**：≤72dp 只画外框 + 左弧（去掉横线），≥96dp 才加横线。

### 稿 D｜日历页 + 月牙镂空（功能最全）

```
   ┌─────────────┐
   │  ▢▢▢        │   三个小方块 = 记录格
   │  ▢▢▢   ◜    │   ◜ = 右上角咬掉的月牙缺口
   │  ▢▢▢        │   底部一条 0.02W 细弧 = 周期
   └─────────────┘
```

- **几何**：底是 0.70W 的圆角方块（"一页"），右上角用 0.26W 的圆做减法咬出缺口；内部 3×3 点阵（点径 0.055W，间距 0.11W），其中一个点（今天）用玫瑰色；底部弧线 60°、离边 0.06W。
- **优点**：日历 + 记录 + 周期三件事都在（最贴"月记"的完整语义）。
- **缺点**：元素最多，48dp 一定脏；必须配一个"极简版"作为小尺寸替代（建议小尺寸退回稿 A）。

### 稿 E｜双圆交叠（经期 × 减脂，产品定位最准）

```
   ┌─────────────┐
   │   ◯◯        │   左圆 = 经期（粉）
   │  ◯██◯       │   右圆 = 减脂（奶白/薄荷）
   │   ◯◯        │   █ = 交叠区（蜜桃），形状天然是月牙
   └─────────────┘
```

- **几何**：底 `#FFF1F4`；左圆 r=0.26W 填 `#F98A9B`，右圆 r=0.26W 填 `#FFF7F8`（描边 `#F7C9D2` 0.02W），圆心距 0.30W；交叠区单独填 `#F7B7A3`（用第三个圆的交集实现，SDF 里做 `max(d1,d2)`）。
- **优点**：**唯一一稿直接表达"经期 × 减脂双轨"**；纯几何、缩放稳、深色底也好做（底换 `#7A2E38`，右圆换 `#3A1E24`）。
- **缺点**：小尺寸下容易读成"两个球"，靠交叠区的蜜桃色救回来；需要保证交叠区 ≥ 0.10W 才看得见。

## 3. 字标（「月记」二字的处理）

图标不写字，但**启动页 / 关于页 / 商店首图**需要字标，建议一条 lockup：

```
      [图标]   月 记
              记录，是为了看见规律
```

| 项 | 规格 |
|---|---|
| 字体 | 思源宋体 SemiBold（衬线更"记录/日记"），备选：苹方-简 Semibold |
| 字号 | 字标 40pt 时图标 56pt；字距 +2%（"月记"两字不要挤在一起） |
| 颜色 | `#C2545E`（浅底）/ `#FBD3DB`（深底） |
| 点睛 | 「记」字最后一笔向右延长 0.6 字宽，末端一个 6pt 圆点——**与图标里的"点"同一符号**，形成呼应 |
| 副标 | 12pt、`#8A6A6F`、"记录，是为了看见规律"（可选，仅商店图用） |

**不建议**：把「月记」塞进应用图标（48dp 下必然糊），也不建议用书法体（与 App 的极简 M3 风格冲突）。

## 4. 五稿横向对比

| 稿 | 经期语义 | 减脂语义 | 记录语义 | 48dp 可读性 | 实现成本（现有生成器） |
|---|---|---|---|---|---|
| A 月牙+点 | ★★★ | ☆ | ☆★ | ★★★ | **最低**（调 3 个参数） |
| **B 环+点** | ★★ | ★★★ | ★★ | ★★★ | 低（弧 + 点，改 render 的绘制段） |
| C 「月」字 | ★★★ | ☆ | ★★★ | ★★（需两档） | 中（笔画用矩形/弧 SDF 拼） |
| D 日历+镂空 | ★★ | ★ | ★★★ | ★ | 高（点阵 + 布尔减法） |
| **E 双圆交叠** | ★★★ | ★★★ | ★ | ★★ | 中（两/三圆 SDF 叠加） |

**推荐组合**：
- **应用图标 = 稿 B**（一个 C 形弧 + 一个点：既是热量环也是月牙，48dp 最稳）；
- **字标 / 启动页 = 稿 C 的「月」字结构 + 字标 lockup**（"月记"读得出来）；
- **商店首图 / 关于页插图 = 稿 E**（讲清"经期 × 减脂双轨"的产品主张）。

如果你更看重"一眼看出是记录 App"，那就反过来：图标用 C（两档细节），商店图用 B。
